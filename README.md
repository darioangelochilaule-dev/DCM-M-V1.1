# DCM-M V1.1 — PostgreSQL Sandbox
Persistent sandbox with PostgreSQL, Prisma, JWT, roles, wallets, double-entry ledger, mint, transfer and reconciliation. Reference: 1 DCM = 1 MZN. Virtual cap: 5,000,000 DCM. TEST ONLY — no real-money issuance.

Default test admin: admin@dcm.local / ChangeMe123!

Local: copy .env.example to .env; npm install; npx prisma generate; npx prisma migrate dev; npm run seed; npm start.
